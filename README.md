# homebrew-webreaper

Homebrew tap for the [WebReaper](https://github.com/alex-on-ai/WebReaper) CLI — an AI-native web scraper that ships as a single binary.

## Install

```bash
brew install alex-on-ai/webreaper/webreaper
```

Or tap first, then install:

```bash
brew tap alex-on-ai/webreaper
brew install webreaper
```

Upgrade with `brew upgrade webreaper`. The formula here is regenerated automatically on every WebReaper release.
